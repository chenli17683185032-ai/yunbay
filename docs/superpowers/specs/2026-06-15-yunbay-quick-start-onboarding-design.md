# 云贝快速启动与普通用户登录后体验设计

日期：2026-06-15

## 背景

当前本地改版前端运行在 `http://127.0.0.1:4174`。登录页已有注册页路由 `/sign-up` 和注册接口 `/api/user/register`，但登录页注册链接受 `self_use_mode_enabled` 影响而隐藏，导致普通访客从主页和登录页看不到注册入口。

目标是把普通用户第一次使用云贝的路径收敛为一个清晰的新手教程，而不是直接进入偏管理员和运营视角的传统后台。同时必须保留 New API 原版普通用户刚需能力，避免误删兑换码、钱包、API 密钥、日志、Playground、聊天、个人资料等功能。

## 约束

1. 注册入口对普通访客公开显示，不受当前测试用 `self_use_mode_enabled` 影响。
2. `register_enabled === false` 时，不应假装可注册，应显示注册暂未开放。
3. 普通用户注册成功后进入新手教程页面。
4. 普通用户登录成功后默认进入新手教程页面。
5. 管理员和 Root 用户继续进入管理后台概览，保留完整后台能力。
6. 兑换码拆成两个视角：
   - 普通用户使用兑换码充值。
   - 管理员创建和管理兑换码。
7. 不删除 New API 原版普通用户刚需功能，只重组普通用户导航。
8. 项目 `AGENTS.md` 明确保护原项目和组织归属信息。实施中不得全局替换、删除或改写 README、license、源码 copyright header、Go module path、package metadata、开源归属链接等受保护信息。
9. 本轮“云贝”品牌处理限定为用户产品体验层和已有云贝组件使用，不做工程级白标迁移。

## 目标体验

### 未登录用户

- 主页和登录页都能看到注册入口。
- 登录页登录按钮下方固定显示：`没有账号？立即注册`。
- 如果注册关闭，显示：`当前暂未开放注册`。
- 当前测试用自用模式不再隐藏注册链接。

### 普通用户

普通用户登录或注册成功后进入 `/quick-start`。该页面是新手教程和启动向导，目标是在 2 到 3 分钟内完成：选择用途、选择模型、确认余额、充值或兑换、下载云贝客户端。

普通用户仍保留以下刚需能力：

- 快速启动
- Playground
- 聊天
- API 密钥
- 使用日志
- 任务日志
- 绘图日志
- 钱包 / 充值
- 兑换码使用
- 个人资料

普通用户不在导航中看到以下管理员或运营视角入口：

- 传统 Dashboard 概览
- 数据看板
- 渠道管理
- 模型管理
- 用户管理
- 兑换码管理
- 订阅管理
- 系统设置
- 登录后的关于入口

### 管理员 / Root 用户

管理员和 Root 用户登录后默认进入 `/dashboard/overview`，继续看到完整后台导航。管理员兑换码管理保留在 `/redemption-codes`。

管理员也可访问 `/quick-start`，但它不是默认落点。

## 路由与跳转规则

### 登录成功

- 普通用户 `role = 1`：默认跳转 `/quick-start`。
- 管理员 `role >= 10`：默认跳转 `/dashboard/overview`。
- Root `role = 100`：默认跳转 `/dashboard/overview`。

如果登录链接带有 `redirect`：

- 管理员尊重 redirect。
- 普通用户只尊重普通用户允许访问的路径。
- 如果普通用户 redirect 指向管理路径，例如 `/channels`、`/users`、`/system-settings`、`/redemption-codes`，则改跳 `/quick-start` 或普通用户兑换路径。

### 注册成功

- 注册成功后优先自动登录并进入 `/quick-start`。
- 如果后端注册接口已建立会话，直接进入 `/quick-start`。
- 如果后端注册接口没有建立会话，则用注册表单里的用户名和密码自动登录一次。
- 如果自动登录失败，跳转 `/sign-in?redirect=/quick-start`，提示用户使用刚注册的账号登录。

### 普通用户访问管理兑换码页

- `/redemption-codes` 仍是管理员兑换码管理页。
- 普通用户手动访问 `/redemption-codes` 时，不进入管理表格，重定向到 `/wallet?section=redeem`。

### 登录后的关于页

- 登录态普通用户访问 `/about` 时重定向到 `/quick-start`。
- 未登录用户仍可访问公开介绍页。

## 普通用户导航设计

普通用户侧边栏组织为：

```text
开始
  - 快速启动

AI 使用
  - Playground
  - 聊天

API
  - API 密钥
  - 使用日志
  - 任务日志
  - 绘图日志

钱包
  - 钱包 / 充值
  - 兑换码

账户
  - 个人资料
```

其中 `兑换码` 第一阶段跳转 `/wallet?section=redeem`，复用现有钱包页的兑换码输入和 `/api/user/topup` 接口。

管理员侧边栏继续使用现有完整导航，并保留 `/redemption-codes` 管理页。

## `/quick-start` 页面设计

### 页面定位

`/quick-start` 是普通用户登录后的第一页面。它不是管理后台概览，而是云贝新手教程。

页面标题：

```text
快速启动云贝
```

副标题：

```text
根据你的用途选择模型，确认余额，然后下载云贝客户端开始使用。
```

页面采用 5 步纵向向导，不做复杂表格。

### 第一步：选择用途

选项：

1. `Web Coding`
   - 用于代码生成、网页开发、调试和项目协作。
2. `聊天`
   - 用于日常对话、写作、总结、翻译和知识问答。
3. `生图等其他`
   - 用于图像生成、多模态、创意探索和其他模型能力。

默认选中 `Web Coding`。

### 第二步：选择模型

列出所有支持模型。每个模型卡片显示：

- 模型名
- 供应商或类型
- 用途标签，例如 Coding、Chat、Image、Reasoning
- 输入费率
- 输出费率
- 选择按钮

费率显示格式：

```text
输入：$x / 百万 tokens
输出：$y / 百万 tokens
```

本轮先用可替换数据表实现 OpenRouter 风格费率展示。后续可接入真实 OpenRouter 费率源或后端统一模型价格接口。

### 第三步：检测账户余额

显示：

- 当前余额
- 预计启动所需最低余额
- 状态

余额充足：

```text
余额充足，可以启动
[继续]
```

余额不足：

```text
余额不足，需要充值或兑换
[去充值] [使用兑换码]
```

`去充值` 跳 `/wallet`。

`使用兑换码` 跳 `/wallet?section=redeem`。

余额换算应复用现有系统配置和格式化逻辑，避免和钱包页显示不一致。

### 第四步：下载云贝轻松开启

显示两个下载卡片：

```text
macOS
适用于 Apple Silicon 与 Intel Mac
[下载 macOS 版]

Windows
适用于 Windows 10 / 11
[下载 Windows 版]
```

本轮只做 UI。点击按钮先显示 toast：

```text
下载资源配置中，请稍后
```

真实下载资源和动作稍后接入。

### 第五步：完成并启动

根据用途显示下一步：

- Web Coding：引导创建 API 密钥或下载客户端。
- 聊天：引导打开聊天。
- 生图等其他：引导打开 Playground 或任务入口。

## 品牌处理

本轮使用已有云贝产品层组件和文案，重点覆盖：

- 快速启动页
- 登录页 / 注册页的用户可见产品文案
- 公开主页已有云贝品牌表达
- 普通用户登录后工作区里的产品感知

不得做工程级全局替换，不改：

- README
- LICENSE
- copyright header
- Go module path
- package name
- Docker image name
- GitHub attribution
- 开源项目归属链接

如需完整白标发行，应另起“白标合规迁移”设计。

## 数据与权限边界

- 导航隐藏不是安全边界。后端原有权限必须保留。
- 前端只做用户体验层面的导航过滤和普通用户重定向。
- 管理员功能不删除，只对普通用户隐藏。
- 普通用户兑换码使用复用钱包能力。
- 管理员兑换码管理保留现有 `/redemption-codes`。

## 测试计划

### 注册入口

- 自用模式开启时，登录页仍显示 `没有账号？立即注册`。
- `register_enabled !== false` 时注册链接存在并指向 `/sign-up`。
- `register_enabled === false` 时显示注册暂未开放。

### 登录跳转

- 普通用户登录成功默认进入 `/quick-start`。
- 管理员登录成功默认进入 `/dashboard/overview`。
- Root 登录成功默认进入 `/dashboard/overview`。
- 普通用户登录时携带管理路径 redirect，会被改送到允许页面。

### 注册跳转

- 注册成功后进入 `/quick-start`。
- 注册后自动登录失败时进入 `/sign-in?redirect=/quick-start`。

### 快速启动页面

- 三个用途选项存在。
- 模型列表显示模型名和费率。
- 余额充足显示继续启动。
- 余额不足显示去充值和使用兑换码。
- macOS 和 Windows 下载卡片存在。
- 下载按钮显示暂未配置提示。

### 普通用户刚需导航

- 普通用户能看到快速启动、Playground、聊天、API 密钥、日志、钱包、兑换码、个人资料。
- 普通用户看不到渠道、模型管理、用户管理、兑换码管理、订阅管理、系统设置。
- 普通用户点击兑换码进入 `/wallet?section=redeem`。

### 管理员导航

- 管理员仍能看到完整后台管理入口。
- 管理员仍能进入 `/redemption-codes` 管理兑换码。

## 实施原则

1. 先补测试或可验证逻辑，避免直接改大面积 UI。
2. 新增 `/quick-start` 页面，少改现有功能页面。
3. 通过角色分流和导航过滤收敛普通用户体验，不删除原功能。
4. 兑换码管理和兑换码使用明确拆分。
5. 品牌处理限定在用户体验层，不违反项目保护规则。
