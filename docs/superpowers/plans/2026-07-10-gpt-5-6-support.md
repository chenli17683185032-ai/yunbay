# GPT-5.6 Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add precise GPT-5.6 family recognition and official fallback pricing to new-api and sub2api without silently mapping unknown 5.6 names to GPT-5.4.

**Architecture:** new-api receives exact default ratio entries and cache ratios, with alias/sol parity tested. sub2api receives exact-only identity mappings, explicit static price objects, corrected bundled dynamic-price entries, and frontend whitelist entries; a pinned full upstream tree is overlaid for real backend/frontend tests because the main repository intentionally omits sub2api manifests.

**Tech Stack:** Go, new-api ratio settings, sub2api Go services, Vue/TypeScript, Bun, pinned upstream `Wei-Shaw/sub2api` commit `ddb1a210ce6742ebd4bd5339b9a0c8f309bcbbf0`.

---

## Supported contract

```text
gpt-5.6       -> gpt-5.6-sol
gpt-5.6-sol   -> gpt-5.6-sol
gpt-5.6-terra -> gpt-5.6-terra
gpt-5.6-luna  -> gpt-5.6-luna
```

Official standard fallback prices in USD per million tokens:

| Model | Input | Cached input | Cache write | Output |
| --- | ---: | ---: | ---: | ---: |
| alias / sol | 5.00 | 0.50 | 6.25 | 30.00 |
| terra | 2.50 | 0.25 | 3.125 | 15.00 |
| luna | 1.00 | 0.10 | 1.25 | 6.00 |

`gpt-5.6-pro`, `gpt-5.6-unknown`, and every other unlisted 5.6 suffix remain unchanged for upstream rejection and have no local price fallback. They must never normalize or bill as GPT-5.4.
